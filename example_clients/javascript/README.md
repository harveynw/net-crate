# JavaScript browser client

Open `index.html` directly in a modern browser, enter the server address and
port, and click **Connect**. No npm install or build step is needed.

You can also pass arguments in the page URL (automatically connects):

```text
file:///absolute/path/to/net-crate/example_clients/javascript/index.html?host=127.0.0.1&port=3000
```
